# Social Connection

Canonical ID: `support.social_connection`; route: `/depression/social`; safety category: `social_action`.

The module prepares a built-in status template locally. Copying uses the browser clipboard only after an explicit user click. It does not read contacts, send messages, or claim delivery. Selecting a status starts structured lifecycle tracking, copying records preparation, and explicit confirmation completes the plan. Discard abandons an active incomplete session. Anonymous use is local only.

Outcomes retain only action/channel types, preparation/confirmation state, aggregate steps, duration, and configuration. They never retain template text, contacts, clipboard content, or conversation history. Generic structured reflection, memory, personalization, and evidence remain the only learning path; module-specific inference is intentionally deferred.
