# Grounding

Canonical ID: `support.grounding`. Route: `/depression/anxietydissolver`. It is structured timed grounding support under the shared safety gateway; no free text is collected.

Start creates an authenticated lifecycle intervention and timer. `Next Technique` confirms the current technique, records aggregate progress, and advances. Suggested timer expiry is informational; early confirmations and elapsed suggestions are stored only as aggregate counts. Four confirmations complete once; Restart abandons only an active incomplete session. Anonymous use is local only.

Outcomes retain only aggregate technique counts, completion rate, suggested-duration counts, duration, and sanitized configuration order/durations. No display text, emotional content, diagnosis, or inferred mood is persisted. Reflection, memory, personalization, and evidence use the generic structured lifecycle pipeline; Grounding-specific learning rules remain deferred.
