# Cognitive Reframing

Canonical ID: `support.cognitive_reframing`; route: `/depression/reality`; safety category: `sensitive_free_text`.

The module uses deterministic keyword matching and structured prompts, not AI, diagnosis, or treatment. Every submitted thought is assessed by `assessSupportInput()` before local analysis. High-risk input is blocked before analysis, clipboard access, lifecycle, outcomes, and learning records.

Safe text remains ephemeral UI state. Authenticated lifecycle records only structured stages and confirmation; anonymous use is local only. Outcomes retain strategy type, safety level, stage counts, completion, and duration only.

Copy is explicit. Its default payload contains the prompt label and generated reframe, never the original thought. Including the original thought is an unchecked local-only option. Clipboard content is never persisted. Generic structured reflection, memory, personalization, and evidence do not receive raw input or generated text.
